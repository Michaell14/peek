# Design

`blink-design-system/` is Blink's overlay design system and the drafts of its next look, as
published to the Design System artifact: tokens (`tokens.json`), the brand book (`README.md`),
motion (`motion.md`), what changes from 0.1 (`changes.md`), and a live preview and guidelines for
each component under `components/`. The **Overlay**, **FirstRun** and **HoldAndTap** previews
are the interactive drafts, and **Directions** compares the four looks (Liquid, which the system
uses, then Graphite, Champagne and Porcelain). Fonts are in `fonts/` (SIL Open Font License) and icons in
`assets/Icons` (Lucide, ISC licence). The previews expect the token variables and `components/bundle.css` to be
loaded first, as the artifact's page does.

Lucide icons (ISC licence), drawn at a 1.75px stroke on a 24px grid. Single ink: every file is drawn in #000000, so tint it in code (`ink-2` at rest, `ink` on hover, `accent` when it means something is on). On the Mac, add each as a template image.

The names are Lucide's own, so a new icon comes from the same set at the same stroke.

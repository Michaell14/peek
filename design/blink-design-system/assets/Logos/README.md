The mark is three tiles, one of them lit, drawn from the app's own `BrandMark` and `BrandGlyph` code.

- `blink-mark.svg`: the mark in colour, for dark grounds (`desktop`, `tile`, `tile-raised`). The unlit tiles are white at 42% (`mark-dim`), the lit one `accent`.
- `blink-mark-template.svg`: the single-ink menu bar glyph, ink #000000; macOS tints it (a template image). Never use it in colour.
- `app-icon.png`: the app icon as the website uses it.

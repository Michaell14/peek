# BrandMark

Blink's mark: three tiles, one of them lit. Use it beside the name in the `CommandBar`, at 14px, and wherever Blink introduces itself.

- The lit tile is always `accent`; the other two are `mark-dim`. Never recolour it, outline it or set it on `accent`.
- On the Mac it is the `BrandMark` view (`size`) and, in the menu bar, the single-ink template image. The files are under Logos.
- Keep clear space of half its size on every side.

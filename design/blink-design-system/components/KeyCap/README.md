# KeyCap

A key drawn as a key, for hints and shortcuts.

- Use the key's name as macOS prints it: `⌥`, `` ` ``, `esc`, `⌘N`, `↩`, `↑`, `↓`. A shortcut of two keys is two keycaps side by side.
- `keycap` type in `ink-2` on `control`, edged in `stroke-strong`, `radius-key`, at least `size-keycap` square.
- Put it after the words it explains: “`esc` to close”, never alone.

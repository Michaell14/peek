    Questions

    How do I install it?

    Download the disk image, open it and drag Blink into Applications. Blink is not notarized by Apple yet, so macOS stops it the first time you open it. Go to System Settings, then Privacy & Security, and choose Open Anyway. You only do this once.

    Why does it ask for Input Monitoring?

    macOS only shows the fn key to apps you allow under Input Monitoring. Blink watches for its shortcut and does not record what you type. If you would rather not allow it, pick an ordinary combination such as ⌥ ` in Settings, which needs no permission. With fn as the shortcut, set System Settings, Keyboard, “Press globe key to” to Do Nothing.

    How does it update?

    Once a day Blink asks GitHub for the newest release and offers to install it. The request carries nothing about you or your Mac. Check for Updates in the menu bar asks straight away, and Settings, About turns the daily check off.

    What does it know about me?

    Nothing it sends anywhere. There is no account, no analytics and no server. Websites you add are stored like a browser stores them, on your Mac, and so are your layouts.

    Is it really free?

    Yes. Blink is open source under the MIT licence, with no paid tier. You can also build it from the source with Xcode 16.

    Which Macs does it run on?

    Any Mac with macOS 14 Sonoma or later, Apple silicon or Intel.
